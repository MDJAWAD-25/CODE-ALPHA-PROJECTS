# CodeAlpha Data Science Internship Projects

This repository contains the completed tasks for the **CodeAlpha Data Science Internship**. The projects demonstrate proficiency in data cleaning, exploratory data analysis (EDA), time-series analysis, feature engineering, and predictive machine learning modeling.

---

## 📌 Projects Included

### 1. Task 2: Unemployment Analysis with Python
* **Objective:** Analyze unemployment rate trends, evaluate the impact of COVID-19, and map seasonal variations.
* **Key Methodology:** 
  * Cleaned missing values and parsed dates using `Pandas`.
  * Visualized overall rates across regions using `Seaborn` and `Matplotlib`.
  * Calculated pre-COVID, 2020, and post-COVID statistical averages to highlight policy implications.

### 2. Task 3: Car Price Prediction with Machine Learning
* **Objective:** Train a regression model to accurately forecast used vehicle prices based on physical and market features.
* **Key Methodology:**
  * Categorical feature encoding via One-Hot Encoding (`pd.get_dummies`).
  * Trained a `RandomForestRegressor` algorithm using `Scikit-learn`.
  * Evaluated performance using $R^2$ score and Mean Squared Error (MSE).

### 3. Task 4: Sales Prediction using Python
* **Objective:** Forecast future sales based on multi-channel advertising budgets (TV, Radio, Newspaper).
* **Key Methodology:**
  * Analyzed platform correlations through pair plots.
  * Implemented a `LinearRegression` model to extract feature coefficients.
  * Formulated actionable insights on marketing strategy and budget prioritization to maximize return on investment (ROI).

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_DataScience_Tasks.git
   ```
2. **Install required packages:**
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```
3. **Run the notebooks:**
   Open Jupyter Notebook or VS Code and execute the `.ipynb` files sequentially.
